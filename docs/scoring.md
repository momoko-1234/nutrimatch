# 規則分數

實際 API 使用 `build_personalized_advice()`，是手寫規則，非臨床訓練模型。

| 條件 | 權重 |
|---|---:|
| 起始值 | 0.15 |
| 每個命中的健康目標 | +0.28 |
| 每個命中的特殊族群／症狀／生活狀態 | +0.20 |
| 每個命中的飲食習慣 | +0.16 |
| 熬夜或輪班，指定營養素 | +0.18 |
| 飲水少於 1.5 L，Magnesium / Probiotics | +0.08 |
| 每週運動至少 4 次，指定營養素 | +0.10 |
| 年齡至少 55 歲，指定營養素 | +0.16 |

上限 `1.0`；已被補充品涵蓋者調整為 `max(0.05, score × 0.45)`。
遞減取前 8 項，同分依規則定義順序。UI 顯示 `round(score × 100)`，是優先度，不是缺乏率。

摘要示意指標：`clamp(round(100 − mean(top8.score) × 25), 1, 99)`，未校準，不能比較健康程度。
產品覆蓋未考慮實際劑量、頻率、吸收或用藥，警語無法窮盡禁忌。
Ollama 只補充文字；prompt 不是正確性保證，原始報告和警語必須保留。
